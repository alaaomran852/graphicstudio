# GS STUDIO - Portfolio Website

موقع بورتفوليو احترافي لمصمم جرافيك، مصمم بأسلوب **Landing Page** عصرية لزيادة طلبات المشاريع.

## المميزات:
- **أزرق تقني (Tech Blue):** هوية بصرية قوية وموحدة.
- **تفاعلي:** يحتوي على سلايدر أعمال تلقائي.
- **تحويل سريع (Conversion):** نظام "بريف" يرسل البيانات مباشرة لواتساب المصمم.
- **متوافق مع الموبايل:** التصميم مرن بالكامل.

## الملفات:
1. `index.html`: الصفحة الرئيسية (البطل، الأعمال، البريف).
2. `services.html`: تفاصيل الخدمات.
3. `portfolio.html`: معرض الأعمال الكامل.
4. `style.css`: ملف التنسيق الموحد.
5. `main.js`: منطق الواتساب والتفاعل.

## ملاحظة:
يجب تغيير رقم الهاتف في ملف `main.js` لاستقبال الرسائل على رقمك الخاص.
